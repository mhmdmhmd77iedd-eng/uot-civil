# المدني · UOT Civil

تطبيق ويب قابل للتثبيت (PWA) لطلاب قسم الهندسة المدنية في الجامعة التكنولوجية: ملازم وأسئلة سابقة لكل مادة، خريطة المتطلبات، حاسبة السعي (بولونيا)، الطلبات، الإعلانات وجدول الامتحانات.

مبادرة طلابية غير رسمية، وليست تطبيقاً تابعاً للجامعة.

تصميم وتطوير المهندس عبدالله أحمد باقر الساعدي · 07886603066

## التشغيل

```bash
npm install
npm run dev      # تطوير
npm run build    # نسخة النشر في مجلد dist
```

مجلد `dist` يُرفع كما هو على أي استضافة ملفات ثابتة (Netlify، Cloudflare Pages).

## الوضع الحالي (1.0.0)
- البيانات محفوظة على جهاز الطالب (localStorage وIndexedDB) لحين ربط الخادم (Supabase + Cloudflare R2).
- وضع المشرف: اضغط رقم الإصدار في الإعدادات 5 مرات.
